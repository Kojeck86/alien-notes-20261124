# Alien Field Notes: The Two Day Earth Review

An alien tourist's one-line review of planet Earth, written after two
days of observation: a deadpan field note about the locals queuing for
bitter bean water, paying extra to have their names spelled wrong on
the cup, and calling it a morning ritual — closed with a tourist's
rating. The program writes exactly that line to `/output/entry.txt`,
deterministically, using only the Python standard library.
